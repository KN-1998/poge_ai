# 术语表

| 术语 | 本项目中的暂定含义 |
|---|---|
| 决策核心 | 负责任务理解、能力判断与动作选择的模型部分 |
| 工作记忆 | 当前任务执行期间需要快速访问的临时状态 |
| 情景记忆 | 交互、事件、过程轨迹及其来源记录 |
| 语义记忆 | 从多条信息中抽象并验证的稳定知识 |
| 主动回顾 | 系统主动判断需要重新读取历史信息的行为 |
| 记忆巩固 | 将多条经验整理为更稳定、紧凑的记忆 |
| 记忆撤销 | 使一条记忆不再参与召回，但保留记录与撤销理由 |
| 动作路由 | 在内部生成、记忆访问、工具执行和委派评审间选择 |
| 路由置信度 | 路由器对本次选择的自评强度，仅用于排序与降级，不作为正确性证据 |
| 评委池 | 用于交叉检查的模型、程序、数据源和环境反馈集合 |
| 调度官 | 负责任务拆解、资源分配、评审选择和结果仲裁的控制层 |
| 教师 | 提供示范、反例与诊断的模型；不是唯一真值来源 |
| 过程监督 | 对中间动作（写记忆、回忆、调用工具）而非仅最终文本给出监督 |
| 环境原生 | 将外部工具、存储和网络视为系统设计的一部分，而非默认可有可无的附加项 |
| 公开蒸馏 | 训练来源、教师身份与贡献可追溯、可署名的蒸馏方式 |
| Planner | 代码中可插拔的生成后端接口，见 `src/poge_ai/planner.py` |
| trace | 一次任务中逐步记录的动作、参数摘要、耗时与结果的审计日志 |

术语会随实验更新。若概念定义发生实质变化，应通过 ADR 记录。
