# 低算力原生记忆 Agent 架构方案（归一化精简版）
> 本方案对完整讨论中的所有观点做逻辑收敛，将探索过程中的矛盾统一为明确的设计权衡，形成一套可落地的端侧智能架构定义。

---

## 一、核心设计目标
本架构不追求稠密大模型路线下的「全知全能、一步作答、基准刷分」，而是针对标准 Transformer 的三个原生缺陷——**Softmax 注意力稀释、静态 KV 不可修改、无能力边界只能硬算**，构建一套低算力、可进化、高实用性的智能体系：
- 小参数核心承载通用决策能力；
- 原生分层记忆解决长上下文遗忘；
- 原生工具通道替代神经网络硬算；
- 生态化训练体系降低自有硬件门槛；
- 最终实现「闭卷分数不高，但真实问题解决能力强」的实用智能。

---

## 二、底层架构：原生记忆与动作体系
所有能力均内建在 Transformer 层内，与 QKV 注意力同层级，不依赖外挂 RAG、提示词工程、硬规则裁剪等外部补丁。

### 1. 可写记忆槽替代静态 KV
抛弃原生 Transformer「KV 只追加、不可改、不可删」的设计，替换为**固定容量、可寻址、可读写的记忆槽**，显存占用不随序列长度增长，从根源避免无限拉长上下文带来的显存膨胀。

### 2. 四个原生门控
所有门控均为可微张量计算，端到端训练，模型自主决策，不写死人工规则：
- **写入门**：控制新信息的写入强度，过滤无效内容；
- **擦除门**：输出连续遗忘权重，覆盖/清理无效旧记忆；
- **更新门**：控制新旧记忆的融合方式，避免灾难性冲突；
- **巩固门**：标记需要压缩、迁移、内化的记忆内容。

### 3. 四层硬件协同的记忆体系
本架构是**环境原生认知系统**：互联网不是外接补丁，而是智能的必要生存环境；模型不追求拥有全部内容，只掌握记忆的索引、判断与调度能力，不同层级硬件严格分工，顺着存储金字塔的成本/速度规律设计，从机制上消除注意力稀释和显存膨胀：

| 层级 | 承载硬件 | 核心内容 | 定位 |
|---|---|---|---|
| 热认知层 | GPU/NPU 显存 | 核心门控权重、激活语义特征、抽象指纹、记忆地址索引，不存放具体事实和原文 | 仅承担判断、决策、特征提取，显存占用恒定且极小 |
| 调度层 | CPU 内存 | 路由表、唤醒索引、记忆槽句柄、任务调度元数据 | 负责 IO 调度、语义唤醒、进程管理，不承载重计算 |
| 本地长期记忆 | 本地磁盘/SSD | 本地工具、缓存内容、压缩历史经验、离线可用资源 | 本地海马体，低成本、大容量，支持离线降级 |
| 泛背景记忆 | 互联网/云端 | 公开知识、实时数据、异构模型、在线工具等全部外部能力 | 外置大脑皮层，是模型能力的主要来源，本地不持有全量副本 |

逻辑层面仍保持三类记忆的独立管理，所有外部记忆不参与实时 Softmax 归一化，仅在命中时动态挂载：
1. **工作记忆**：小容量高精度，存放当前任务临时信息，仅这部分参与实时注意力；
2. **情景长期记忆**：压缩存储事件、经验、结论，按需唤醒；
3. **参数语义记忆**：内建于 FFN/MoE 专家，高频经验缓慢固化为常识，保证核心稳定。

记忆的所有权与使用权彻底分离：99% 的原始内容永远不需要进入 GPU，GPU 仅保留语义目录，需要时由 CPU 从磁盘或网络按需读取。

### 4. 隐式主动回顾与自动唤醒
新增独立回顾查询头，由模型根据当前置信度、记忆冲突、任务依赖自动触发：召回的旧记忆在隐状态内完成重放、校验并写回，全程不生成 token、不占用上下文窗口，实现实时记忆巩固。相似零散记忆自动合并为抽象结论，提升记忆密度。

CPU 侧承担原生语义唤醒能力，而非被动等待用户提问：GPU 特征激活后，CPU 自动根据语义关联提前挂载相关记忆和工具的句柄。互联网中新出现的工具、数据源、模型只要被公开索引，中枢无需重训、无需版本更新即可自动识别能力、更新路由，实现能力随环境自动生长，即「在网络中自动长出血肉」。

### 5. 三通道路由机制
每步推理先经过路由门控选择解决路径，不再只有「生成文本」单一出口：
- **内部计算通道**：语义理解、创作、常识判断等模型可可靠完成的任务，直接生成文本；
- **记忆通道**：需要历史经验、长期信息时，主动检索分层记忆；
- **工具动作通道**：精确计算、实时信息、代码执行、硬件控制等任务，直接输出结构化动作，而非生成 JSON 文本。

工具接口采用统一语义编码，模型读取接口定义即可零样本适配新工具，无需针对每个工具单独微调。工具返回结果经门控分流写入对应记忆层级，报错自动触发回顾重试，高频能力可逐步内化，减少重复调用。

## 三、训练体系：生态化自举训练
不依赖自有大规模 GPU 集群做全量预训练，通过异构智能生态完成能力培养，学生学习的是「学习与决策的元能力」，而非复刻教师输出。

### 1. 三层角色分工
1. **学生核心**：即端侧小模型，是最终交付的智能体，仅核心门控和推理层需要自有算力训练；
2. **统御调度官**：由成熟 Transformer 承担，不需要最强生成能力，负责任务拆解、评委选聘、结果仲裁、信用管理、成本控制，是「管 AI 的 AI」；
3. **动态评委池**：异构、弹性的能力集合，包含不同厂商云端模型、开源模型、垂直领域模型、传统 CPU 算法、确定性工具、公开人类经验，按需调用、用完即释放，不占用自有固定算力。

### 2. 完整训练流程
1. **冷启动阶段**：教师输出完整认知动作轨迹（信息取舍、回顾时机、工具选择），监督信号直接作用于学生的门控参数，而非仅拟合输出文本；
2. **过程监督阶段**：学生每一步记忆操作、路由决策都由调度官实时校验，错误直接定位到具体门控，配合故障注入测试覆盖边缘场景；
3. **流式进化阶段**：模型接入实时互联网数据流，在线处理多源信息，评委池交叉校验、工具真实执行结果作为最终 ground truth，能力随数据持续迭代，不需要全量重训。

### 3. 多维度奖励目标
- 任务结果正确率；
- 长程信息召回率；
- 记忆槽利用效率（冗余惩罚）；
- 工具调用必要性与算力成本；
- 错误重试与自我修正能力。

### 4. 核心特性
教师只教决策方法，不输出标准答案，学生能力不被单个教师上限锁死；配合真实环境反馈和异构生态，学生在垂直场景的最终表现可以超过任何一个参与训练的评委，实现「师不必贤于弟子」。

### 5. 初代调度官选型
冷启动阶段选择 Claude 作为高权重教练模型，利用其 Constitutional AI 的规则校验、过程审查、长流程跟踪能力快速建立门控基线；但仅作为过渡型外部顾问，不掌握最终决策权，核心调度框架保持开源，敏感场景使用本地开源模型替代，成熟后完成全开源替换，不形成厂商锁定。

## 五、开源治理体系
开源是本架构的内生要求，而非附加选项，通过三层规则平衡公共属性与商业可持续：
1. **核心层强 Copyleft 约束**：核心权重、门控、通信协议、训练日志、核心数据永久开源，所有衍生作品必须同等开源，禁止公共基础设施私有化；
2. **生态层开放商业化**：垂直模型、行业工具、记忆库、托管服务、硬件适配允许正常收费，参与方可通过服务和场景落地获得合理收益；
3. **中立基金会共治**：全训练流程公开可审计，所有参与者均可提出改进，重大路线由社区公开评审，不被单一商业主体控制。

所有训练过程采用公开蒸馏模式：能力来源全程留痕、永久署名，承认所有教师和贡献者的价值，禁止无署名灰色蒸馏和无回馈搭便车行为，形成「公开学习、公开迭代、成果共享」的协作规则。

## 六、算力模型：重构硬件分工
通过架构拆分把高端 GPU 的刚性需求转化为异构算力的弹性协同，适配算力受限的现实环境。

### 1. 硬件职责重新划分
- **GPU/NPU**：仅承担小参数核心的推理、门控决策和少量核心训练，算子简单、显存需求低，国产加速芯片、消费级显卡均可承载，不依赖高互联、先进制程集群；
- **CPU**：承担所有确定性机械计算、数据清洗、记忆存储、工具执行、后台整理，复用成熟工业软件生态，通用服务器和嵌入式芯片即可规模化扩展。

### 2. 成本结构优化
- 固定硬件投入（CapEx）极低：无需自建万卡集群，自有资源仅需覆盖小核心训练和端侧部署；
- 弹性开销（OpEx）按需使用：云端评委和算力可跨平台调度，利用闲置实例、开源模型、异构资源做成本套利，边际训练成本随规模快速下降。

### 3. 端侧部署能力
核心模型可量化到 2~4bit，运行在 MCU、RISC-V、嵌入式 NPU 上；高频工具和常用记忆本地缓存，支持断网降级，联网时同步云端更新，适配离线随身 Agent、机器人等端侧场景。

## 七、设计权衡与能力边界
所有「不完美」均为主动选择的 tradeoff，而非架构缺陷：

| 主动放弃的能力 | 换取的核心价值 |
|---|---|
| 无工具闭卷高分数、全量事实硬记忆 | 真实任务下的低幻觉、结果可验证 |
| 单步即时响应、零等待输出 | 多步校验带来的高可靠性、错误可修正 |
| 纯 GPU 裸跑、完全无环境依赖的独立能力 | 四层硬件协同下的极低显存占用与无限能力外延 |
| 完全离线封闭场景下的满性能 | 开放网络环境下的资源整合与持续自进化能力 |
| 全流程可解释、每一步可审计 | 自主记忆调度带来的灵活性与低算力开销 |

### 离线分级降级机制
模型能力随环境条件分层降级，而非非黑即白：
1. 纯 GPU 无 CPU/存储协同：仅保留核心特征和门控，无法完成完整任务，是架构原生设计而非缺陷；
2. 有 CPU 和本地磁盘、但断网：依托预缓存工具、本地记忆和离线资源工作，可覆盖固定场景；
3. 联网环境：完整能力解锁，整个互联网作为泛背景记忆提供全部能力外延。

该设计同时带来原生安全特性：终端仅存储索引和抽象特征，不保存完整敏感数据，设备隔离不会直接泄露原始内容。

### 明确适用场景
- 高优先级：端侧随身 Agent、机器人控制、工业排障、嵌入式系统、硬件开发辅助、长流程工程任务；
- 不适用场景：完全无工具的封闭环境、毫秒级硬实时控制、纯短文本创作等不需要外部资源的任务。

## 八、架构定位与历史角色
### 1. 规模无关的通用架构
小参数端侧模型只是冷启动切入点，本架构不局限于小模型：核心推理能力、记忆槽容量、工具/评委池规模三者独立可缩放，从 1B 级端侧到万亿级云端核心均可复用，云端大模型接入同样能获得数量级的算力效率提升。

### 2. 过渡性脚手架定位
本架构不是智能的终极形态：它依然基于冯·诺依曼硬件、存储计算分离和现有互联网协议，显式门控调度距离生物级认知、全具身智能仍有本质差距，其历史使命是跑通开放记忆、工具协同、开源共治的完整体系，成为下一代更高阶智能的基础平台，允许自身被迭代和超越。

### 3. 原创性说明
本架构的创新属于系统级范式整合：所有单个技术组件均来自公开学术与开源生态，而将内生记忆、原生工具、分层存储、异构评审、开源治理、算力套利整合为一套自洽体系的完整方案，为独立的架构原创，可通过公开时间戳文档固定优先权。

## 九、方案本质
这不是「弱化版 GPT」，而是另一条环境原生的智能路径：
- 稠密大模型走「天才路线」，靠极致算力堆出全知、独立、自包含的大脑；
- 本架构走「工程师路线」，模型中枢小而精，不追求全知全能，但具备清晰的自我认知、资源整合能力和复盘进化能力，把整个互联网和成熟工具生态作为自身的外延，以极低的硬件门槛解决真实世界的复杂问题。
