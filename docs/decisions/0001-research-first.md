# ADR 0001：先验证系统基线，再研究原生模型改造

- 状态：Accepted
- 日期：2026-11-13

## 背景

完整设想同时涉及模型结构、记忆机制、工具路由、异构评审、硬件分层和开源治理。若直接开发完整系统，出现效果变化时很难归因，也会显著提高首个可运行版本的成本。

## 决策

先实现基于现成模型的系统级 baseline，再逐项替换记忆、路由和监督机制。每项改造必须有对照实验和消融结果。

基线的具体形态由 ADR 0003 固定：SQLite 记忆 + 规则路由 + 受限工具 + JSONL 轨迹。

## 后果

- 优点：更容易复现、定位问题和判断真实收益。
- 代价：早期成果可能看起来不像最终设想中的“底层原生架构”，容易被误读为放弃原目标。
- 复审条件：基线稳定、评测协议成熟后，启动学习式记忆模块实验。
