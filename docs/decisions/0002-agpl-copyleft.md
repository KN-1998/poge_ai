# ADR 0002：采用 AGPL-3.0-or-later 作为代码许可

- 状态：Accepted
- 日期：2026-11-13

## 背景

项目立场是“全流程强制开源、禁止公共基础设施私有化、网络服务也必须回馈”。需要选择一个能覆盖“只提供服务、不分发二进制”场景的强 Copyleft 许可。候选包括 MIT、Apache-2.0、GPL-3.0、AGPL-3.0、以及 SSPL 一类自定义许可。

## 决策

- 代码采用 **GNU Affero General Public License v3.0 or later**，仓库根目录 `LICENSE` 为 FSF 官方全文，未做修改。
- 文档采用 **CC BY-SA 4.0**，写入 `NOTICE`。
- 第三方依赖、模型权重与数据集不因本仓库许可而被重新授权。

## 后果

- 优点：与服务化场景下的源码回馈要求匹配；许可文本成熟、可被法律体系识别；避免了 SSPL 之类的非 OSI 许可风险。
- 代价：部分商业集成方会回避 AGPL；无法强制社区遵守署名与回馈规范，只能靠记录与舆论约束。
- 未决：未来发布的模型权重是否、以及如何适用 AGPL，尚无结论；发布前必须新增 ADR。
- 复审条件：若项目决定提供官方托管服务并需要商业化，需重新评估（注意：AGPL 并未禁止收费，只要求源码可得）。
